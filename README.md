## 🔎 RAG Pipeline

A production-oriented **Retrieval-Augmented Generation pipeline** for document ingestion, embeddings, vector search, retrieval, and LLM-powered responses.

### Pipeline

```text
Documents
    │
    ▼
Document Processing
    │
    ▼
Chunking
    │
    ▼
Embeddings
    │
    ▼
Vector Database
    │
    ▼
Similarity Search
    │
    ▼
Retrieved Context
    │
    ▼
LLM
    │
    ▼
Context-Aware Response
```
